# CLAUDE.md

The portfolio site: Next.js 13 App Router, Tailwind, deployed on Vercel.
Each page is a route folder in `src/app/`, for example `src/app/ai-engineer`.

## PR Tracker data updates

When the user pastes Reddit comments from the Express Entry PR timeline
megathread, or asks to update the PR tracker, follow
[src/app/pr-tracker/CLAUDE.md](src/app/pr-tracker/CLAUDE.md). Read it first.
It explains how to merge the comments into `src/app/pr-tracker/data.json`
without losing any existing data.
